# Thư mục Notebooks

Thư mục này dùng để lưu trữ các Jupyter Notebook phục vụ quá trình phân tích khám phá dữ liệu (EDA), thử nghiệm mô hình và trực quan hóa kết quả:

## Định hướng cấu trúc notebook
* **`01_exploratory_data_analysis.ipynb`**: Khám phá phân phối dữ liệu OULAD, tỷ lệ trễ hạn, phổ điểm bài kiểm tra, mức độ tương tác LMS.
* **`02_feature_engineering_experiments.ipynb`**: Thử nghiệm các phương pháp trích xuất đặc trưng theo tuần và kỹ thuật rời rạc hóa cho mạng Bayesian.
* **`03_model_dbn.ipynb`**: Thử nghiệm học cấu trúc và tham số Dynamic Bayesian Network bằng `pgmpy`.
* **`04_model_lstm.ipynb`**: Thử nghiệm kiến trúc mạng LSTM dự đoán theo chuỗi thời gian bằng `PyTorch`.
* **`05_model_evaluation.ipynb`**: Đánh giá so sánh chỉ số (Accuracy, Precision, Recall, F1, AUC-ROC) theo từng mốc tuần $T$.

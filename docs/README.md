# Tài liệu Đồ án DSS (IS254.R11)

Thư mục này lưu trữ tài liệu đặc tả và kế hoạch thực hiện đồ án môn học:

## Danh mục tài liệu
1. **`DSS_plan.docx`**: Bản kế hoạch đồ án hoàn chỉnh định dạng Microsoft Word.
2. **`DSS_plan.txt`**: Nội dung văn bản trích xuất từ kế hoạch đồ án, thuận tiện xem nhanh trên Git / IDE hoặc phân tích bằng script.

## Tóm tắt nội dung kế hoạch
* **Tên đề tài:** Thiết kế Hệ Hỗ trợ Ra Quyết định (DSS) Dự đoán Nguy cơ Học tập của Sinh viên bằng Dynamic Bayesian Network (DBN) và LSTM trên bộ dữ liệu OULAD.
* **Môn học:** Hệ thống Hỗ trợ Ra quyết định (IS254.R11) - ĐH Công nghệ Thông tin (UIT - ĐHQG-HCM).
* **Nhóm thực hiện:** Nhóm 8 (Bạch Hồ Bắc - 23520086, Đặng Công An - 23520002).
* **Giảng viên hướng dẫn:** Thầy Nguyễn Hồ Duy Trí.
* **Các mốc chính:**
  - Giai đoạn 1: Khám phá & tiền xử lý dữ liệu OULAD, xây dựng pipeline đặc trưng theo tuần.
  - Giai đoạn 2: Huấn luyện và đánh giá DBN, LSTM và mô hình đối chứng (Baseline).
  - Giai đoạn 3: Xây dựng backend suy luận FastAPI.
  - Giai đoạn 4: Xây dựng Dashboard Streamlit hỗ trợ cố vấn học tập ra quyết định can thiệp sớm.
